Workflow

How I Work

Clear, organized production from raw footage and creative direction to a finished short-form deliverable.

  1. 01

    Receive the Footage and Brief

    Understand the message, audience, creative direction, and deliverables before editing.

  2. 02

    Build the First Cut

    Create a clean version that communicates the core message clearly and keeps the pacing tight.

  3. 03

    Create Variations

    Develop different hooks, openings, captions, pacing, visual treatments, or creative directions when needed.

  4. 04

    Quality Check

    Review captions, timing, formatting, audio, visual consistency, and the mobile viewing experience.

  5. 05

    Deliver Organized Files

    Use clear filenames and organized exports that are easy to review, revise, and use.

File Naming, Every Time

Motivation_QuestionHook_V2

No "final_v3_ACTUAL" files. Every export is named by its creative direction and version.
