How I Work

Clear, organized editing from raw footage to a finished short-form deliverable.

  1. 01

    Receive the Footage and Brief

    Understand the required message, audience, and deliverables before editing.

  2. 02

    Build the First Cut

    Create a clean version that communicates the core message clearly.

  3. 03

    Create Variations

    Develop different hooks, openings, captions, pacing, or visual treatments when needed.

  4. 04

    Quality Check

    Review captions, timing, formatting, audio, and the mobile viewing experience.

  5. 05

    Deliver Organized Files

    Use clear filenames and organized exports that are easy to review and use.
